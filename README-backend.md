# THE LEARNER — ব্যাকএন্ড সেটআপ (আপডেট ২)

এই ফোল্ডারে আছে:
- `migration-2.sql` — ডেটাবেজের নতুন টেবিল (কাঠামো, ইতিহাস, AI, চ্যাট)
- `ai/index.ts` — Supabase Edge Function (সব AI-এর সাথে কথা বলে; API Key এখানেই নিরাপদ থাকে)

## ধাপ ১: ব্যাকআপ (বাধ্যতামূলক, ২ মিনিট)
অ্যাডমিন প্যানেল → **💾 Backup** → "Download backup (JSON)"। ফাইলটি নিরাপদ জায়গায় রাখুন।

## ধাপ ২: ডেটাবেজ আপডেট
Supabase → **SQL Editor** → **New query**। প্রতিবার ঘরটা পুরো খালি করে (Ctrl+A, মুছুন) `migration-2.sql`-এর **একটি ব্লক** (ক, খ, গ, ঘ, ঙ, চ) পেস্ট করে **Run** চাপুন। সব ব্লক শেষ হলে হয়ে গেল। বারবার চালালে ক্ষতি নেই।

> ব্লক খ চালানোর পর শিক্ষার্থীরা আর সবার জন্য প্রশ্ন যোগ/সম্পাদনা/মুছতে পারবে না (শুধু অ্যাডমিন)।

## ধাপ ৩: AI ফাংশন চালু করা
Supabase → **Edge Functions** → **Deploy a new function** → নাম দিন ঠিক `ai` → `ai/index.ts`-এর পুরো লেখা পেস্ট করে **Deploy**।
(**Verify JWT** চালু রাখুন, এটাই ডিফল্ট।)

## ধাপ ৪: API Key সেট করা (শুধু যেসব AI চান)
Supabase → **Edge Functions → Secrets** (বা টার্মিনালে `supabase secrets set নাম=চাবি`):

| AI | Secret নাম | চাবি কোথায় পাবেন |
|---|---|---|
| ChatGPT | `AI_KEY_OPENAI` | platform.openai.com |
| Gemini | `AI_KEY_GEMINI` | aistudio.google.com |
| Claude | `AI_KEY_ANTHROPIC` | console.anthropic.com |
| DeepSeek | `AI_KEY_DEEPSEEK` | platform.deepseek.com |
| Perplexity | `AI_KEY_PERPLEXITY` | perplexity.ai/settings/api |

চাবি কখনো ওয়েবসাইটের কোডে বা অ্যাডমিন পেজে লিখবেন না। সেট করার পর অ্যাডমিন প্যানেল → **🤖 AI** ট্যাবে প্রতিটি AI-এর পাশে "🔑 Key set" দেখাবে।

## ধাপ ৫: মডেলের নাম যাচাই
অ্যাডমিন প্যানেল → 🤖 AI → প্রতিটি AI খুলে **Model** ঘরটি দেখুন। নামগুলো শুরুর অনুমান; প্রতিটি কোম্পানির সর্বশেষ নাম তাদের ডকুমেন্টেশনে মিলিয়ে নিন (পুরোনো নাম বন্ধ হয়ে গেলে "এই AI সাময়িকভাবে কাজ করছে না" দেখাবে)।

## ধাপ ৫.১: খরচ নিয়ন্ত্রণ
প্রতিটি AI-এর "দৈনিক সীমা (প্রতি ব্যবহারকারী)" ও "সর্বোচ্চ উত্তরের টোকেন" আর 🤖 AI ট্যাবের "মোট দৈনিক সীমা" ঠিক করুন। কোম্পানিগুলো ব্যবহার অনুযায়ী টাকা নেয়; নিজেদের ড্যাশবোর্ডেও সীমা (budget) বসিয়ে রাখুন।

## ধাপ ৬: ওয়েবসাইট আপলোড
`thelearner-app.zip`-এর ছয়টা ফাইল গিটহাবে আপলোড করুন (index.html, admin.html, sw.js, manifest.webmanifest, আইকন দুটি)।

## ধাপ ৭: প্রশ্নের কাঠামো
অ্যাডমিন প্যানেল → **🗂️ Structure**। ICT (৬ অধ্যায়), English (টপিক) আর বাংলা গদ্যে "গন্তব্য কাবুল" শুরুতে দেওয়া আছে। বাকি বিষয়ের অধ্যায়/রচনার নাম ও কীওয়ার্ড আপনার সিলেবাস অনুযায়ী যোগ করুন (এক লাইনে একটি, "নাম | কীওয়ার্ড১, কীওয়ার্ড২")। যত ভালো কাঠামো, শ্রেণিবিন্যাস তত নির্ভুল।
